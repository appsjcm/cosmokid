Cosmo Kid v69 - Mejoras seguras

Cambios principales:
- Añadido botón LITE/HD dentro del juego.
- En móvil se activa LITE automáticamente para mejorar FPS.
- El modo LITE reduce parallax, partículas ambientales, postFX y viñetas pesadas.
- El modo HD mantiene el aspecto premium.
- Si el juego baja mucho de FPS, activa LITE automáticamente si el jugador no eligió modo.
- Actualizado caché del service worker a v69 para GitHub Pages.
- Actualizadas rutas con ?v=69 para evitar versiones antiguas.
- Diagnóstico actualizado a v69.

Cómo probar:
1. Sube todo el contenido a GitHub Pages.
2. Abre index.html o game.html.
3. Pulsa el botón LITE/HD arriba a la izquierda para cambiar rendimiento.
4. En móvil, usa LITE si notas tirones.
